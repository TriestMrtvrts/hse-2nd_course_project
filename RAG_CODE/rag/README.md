# RAG Module

Актуальное описание проекта, экспериментального контура и команд запуска находится в корневом файле:

```bash
readme.md
```

Этот каталог содержит:
- `prep_rag_data.py` — подготовку корпуса и индекса;
- `rag_inference.py` — retrieval и LLM-вызовы для продукта;
- `model_utils.py` — разрешение локальных путей к моделям;
- `converted_md/` — markdown-версии документов;
- `data/` — исходные файлы корпуса;
- `hse.sqlite3` — база знаний.
